We are going to see how to customize table open UI client using JavaScript in the presentation  model.  The first step is to make sure the custom GFI goes into the correct location.  In this example, I am using a dedicated client and the custom GFI goes into the table root  directory, public, the language, the tail, script, table and then custom folder.  This is the JSON that we are creating.  If you look at the GFI by itself, we have created a class, a constructor and then the  custom code goes here.  The next step is to go into the table open UI client, go into the administration application,  manifest files view and create a new request for their custom GFI.  Here we have already created.  We will customize the lifecycle bin via model.js.  The next step is to go into the same screen administration application and we go into manifest  administration view.  And here you create a new entry for the applet against which you want to execute the  custom logic.  You see each type of presentation model.
